VirtualState · Pitch animado (55 s)

Uso local: abre index.html en el navegador.
GitHub Pages: sube index.html a la raíz del repositorio y activa Pages (Settings > Pages > rama main, carpeta / root).

Controles:
  T  -> cambia tema (claro para proyector / oscuro para pantalla)
  R  -> reinicia la animación
  Botones discretos arriba a la derecha (hacen lo mismo)
  Al terminar, un clic en la imagen la reinicia.

Forzar tema desde el enlace:  ...index.html?tema=claro  o  ?tema=oscuro
El navegador recuerda el último tema elegido.

Escenas: 0-17 s título · 17-37 s la red · 37-55 s marketplace y cierre.
